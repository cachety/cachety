# Cachety

**روی کارت شناسایی و مدارک حساستان واترمارک بگذارید، بدون اینکه هرگز از دستگاهتان بیرون بروند.**

Cachety روی فایل‌های PDF و عکس‌ها (کارت ملی، گذرنامه، فیش حقوقی، برگهٔ مالیاتی، گردش حساب بانکی) واترمارک می‌گذارد، آن هم کاملاً داخل مرورگر شما. هیچ فایلی هرگز آپلود نمی‌شود: اصلاً سروری وجود ندارد که بتواند فایلی دریافت کند. رایگان است، ثبت‌نام نمی‌خواهد، ردیابی ندارد و متن‌باز است.

### 👉 همین حالا استفاده کنید: **[cachety.com](https://cachety.com)**

به زبان‌های انگلیسی، فرانسوی، اسپانیایی، عربی، فارسی، ژاپنی و چینی ساده‌شده در دسترس است.

![Cachety: یک PDF که داخل مرورگر واترمارک شده است](docs/preview.png)

## چرا این پروژه ساخته شد

مدام از ما کپی مدارکمان را می‌خواهند: برای اجارهٔ خانه، شروع یک کار تازه یا باز کردن حساب بانکی. کپی ساده، وقتی فرستاده شد، ممکن است برای هر کاری دوباره استفاده شود، حتی جعل هویت. واترمارکی که بنویسد این کپی برای چیست، برای چه کسی است و در چه تاریخی داده شده، آن را فقط به همان یک کار گره می‌زند. سرویس ملی فرانسه برای کمک به قربانیان جرائم سایبری، [Cybermalveillance.gouv.fr](https://www.cybermalveillance.gouv.fr)، دقیقاً همین را توصیه می‌کند.

بیشتر ابزارهای آنلاین واترمارک برای این کار، کارت شناسایی شما را روی سرورهای خودشان آپلود می‌کنند. Cachety این کار را نمی‌کند.

## از نسخهٔ آنلاین استفاده کنید: بهترین راه همین است

لازم نیست چیزی نصب یا بیلد کنید. **[cachety.com](https://cachety.com)** همان نسخه‌ای است که به همه پیشنهاد می‌کنیم:

- **به همان اندازه خصوصی.** حتی به‌صورت آنلاین، فایل‌هایتان هرگز از دستگاهتان بیرون نمی‌روند: صفحه همهٔ کار را داخل مرورگر شما انجام می‌دهد و از نظر فنی اجازه ندارد اطلاعاتی به جایی بفرستد. خودتان امتحان کنید: صفحه را باز کنید، حالت هواپیما را روشن کنید و روی یک سند واترمارک بگذارید.
- **محافظت بهتر.** سایت رسمی با مجموعهٔ کامل هدرهای امنیتی ارائه می‌شود (محافظت در برابر clickjacking، ‏HSTS، جداسازی بین‌مبدأ و یک Content-Security-Policy سخت‌گیرانه برای هر صفحه). نسخه‌ای که خودتان روی یک وب‌سرور ساده راه بیندازید، اغلب بعضی از این‌ها را ندارد.
- **همیشه به‌روز.** اصلاحات امنیتی و بهبودها در بازدید بعدی به دستتان می‌رسد، بدون اینکه لازم باشد چیزی را به‌روز کنید.
- **همه‌جا سریع.** از طریق یک CDN جهانی ارائه می‌شود، پس هر جا که باشید سریع باز می‌شود، و بعد از یک بار بارگذاری بدون اینترنت هم کار می‌کند.
- **راحت روی هر دستگاهی.** روی رایانه، آیفون و اندروید کار می‌کند. می‌توانید آن را مثل یک اپ به صفحهٔ اصلی گوشی اضافه کنید؛ در اندروید هم می‌توانید فایل را مستقیم با Cachety به اشتراک بگذارید.
- **راهنما هم دارد.** یک تور راهنما به کسانی که بار اول می‌آیند نشان می‌دهد از کجا شروع کنند، و راهنماهای کاربردی موقعیت‌های رایج را توضیح می‌دهند.

میزبانی شخصی همچنان ممکن است و کاملاً پشتیبانی می‌شود (پایین‌تر را ببینید)، برای سازمان‌هایی که به آن نیاز دارند.

## امکانات

- **PDF و عکس:** ‏JPG، ‏PNG، ‏WebP، ‏GIF، ‏BMP، ‏AVIF و عکس‌های آیفون (HEIC). یک فایل یا چند فایل با هم (تا ۲۰۰ مگابایت برای هر فایل و ۵۰۰ صفحه برای هر PDF).
- **واترمارک روی تمام صفحه**، یکی‌شده با تصویر. با ویرایش سادهٔ PDF پاک نمی‌شود و چیدمانش در هر کپی فرق می‌کند. فونت، اندازه، رنگ، میزان شفافیت و جلوهٔ موج را خودتان انتخاب می‌کنید.
- **الگوهای آماده** (اجاره، بانک، استخدام…) و دکمه‌ای برای افزودن تاریخ امروز با یک لمس.
- **حذف اطلاعات پنهان:** متن قابل انتخاب، فراداده‌ها و موقعیت GPS عکس‌ها. هر صفحه از نو، از پیکسل‌ها ساخته می‌شود.
- **پوشاندن اطلاعات:** شمارهٔ IBAN، شمارهٔ مالیاتی یا عکس را سیاه کنید. محتوا واقعاً حذف می‌شود، نه اینکه فقط رویش پوشانده شود.
- **کپی‌های قابل ردیابی:** تاریخ و یک کد یکتا روی هر کپی، به‌اضافهٔ فهرستی از کپی‌ها که خودتان نگه می‌دارید.
- **چند گیرنده:** برای هر گیرنده یک نسخهٔ جداگانه (تا ۲۰ گیرنده)، همه در یک دانلود.
- **رمز:** رمزگذاری PDF با AES-256 ‏(PDF 2.0)، همراه با سازندهٔ رمز قوی و پاک شدن خودکار کلیپ‌بورد.
- **حداکثر حجم برای هر فایل** (۱، ۲، ۵ یا ۱۰ مگابایت) برای سامانه‌هایی که حجم آپلود را محدود می‌کنند.
- **یک PDF واحد** به ترتیبی که خودتان می‌خواهید (با کشیدن و رها کردن)، یا یک فایل فشردهٔ **ZIP**.
- **روی گوشی کار می‌کند**، می‌شود آن را مثل یک اپ نصب کرد، و بعد از بارگذاری **بدون اینترنت** هم کار می‌کند.
- **۷ زبان**، با چیدمان راست‌به‌چپ برای عربی و فارسی و فونت‌های مخصوص هر خط.
- **تور راهنما** برای کسانی که بار اول می‌آیند؛ وقتی به نظر برسد کسی نمی‌داند از کجا شروع کند، پیشنهاد می‌شود.
- **۴۲ راهنمای کاربردی** برای موقعیت‌های روزمره در فرانسه، بریتانیا، اسپانیا و آمریکای لاتین، جهان عرب، ایران، ژاپن و چین.
- **۴۵ مقایسهٔ راستی‌آزمایی‌شده** با ابزارهای دیگر واترمارک (FiligraneFacile، ‏iLovePDF، ‏Smallpdf، ‏PDF24، ‏Adobe Acrobat و غیره)، همراه با منبع، از جمله مواردی که ابزار دیگری انتخاب بهتری است.

## حریم خصوصی از اساس، و قابل بررسی

- همهٔ پردازش داخل مرورگر انجام می‌شود (pdf.js، ‏canvas، ‏pdf-lib). فایل‌ها فقط در حافظه و به‌شکل اشیای `File`/`Blob` وجود دارند.
- سیاست Content-Security-Policy قاعدهٔ `connect-src 'self'` را تعیین می‌کند، پس خود مرورگر هر درخواستی به دامنهٔ دیگر را رد می‌کند، حتی اگر به هر شکلی کد مخربی اجرا شود.
- نه کوکی، نه آمارگیری، نه اسکریپت شخص ثالث، نه حساب کاربری. فقط تنظیمات نمایش در `localStorage` نگه داشته می‌شود. فونت‌ها را خود سایت ارائه می‌کند.
- هر تضمین با آزمون‌های خودکاری اعمال می‌شود که با هر تغییر اجرا می‌شوند: CSP، نبودِ منابع خارجی، پاک‌سازی فایل‌های خروجی، و شبیه‌سازی یک تلاش برای بیرون کشیدن اطلاعات.

مدل کامل تهدیدها، کنترل‌ها و آزمون‌ها: **[docs/security.md](docs/security.md)**. برای گزارش یک آسیب‌پذیری، **[SECURITY.md](SECURITY.md)** را ببینید.

## میزبانی شخصی

لازم نیست به نسخهٔ منتشرشدهٔ ما اعتماد کنید: سایت یک خروجی ایستا است که می‌توانید خودتان میزبانی کنید.

پیش‌نیاز: [Bun](https://bun.sh).

```sh
git clone https://github.com/cachety/cachety
cd cachety
bun install
bun run build      # static export in out/
bunx serve out     # or any static file server
```

پوشهٔ `out/` را می‌توانید همان‌طور که هست روی هر میزبان ایستایی بگذارید. هر صفحه Content-Security-Policy خودش را در یک تگ `<meta>` دارد، پس قفل شبکه حتی بدون هدرهای HTTP ما هم کار می‌کند. برای اینکه همان محافظت cachety.com را داشته باشید، هدرهای فایل `out/_headers` را هم تنظیم کنید. برای Cloudflare Pages، ‏GitHub Pages و سرورهای دیگر، [docs/deploy.md](docs/deploy.md) را ببینید.

## توسعه

```sh
bun run dev        # development server
bun test           # unit tests and static security checks
bun run test:e2e   # browser suite (CHROMIUM_EXE=/path/to/chrome to use a local Chrome)
```

فناوری‌ها: Next.js (خروجی ایستا)، React، ‏Tailwind CSS، ‏PDF.js، ‏pdf-lib، ‏libheif.

- متن‌های رابط کاربری: `lib/i18n.tsx` (فرانسوی، انگلیسی، ژاپنی، چینی) و `lib/locales/<lang>/strings.ts` (اسپانیایی، عربی، فارسی).
- متن‌های سایت: `lib/site-copy.ts` و `lib/locales/<lang>/site.ts`. فراداده‌های صفحه‌ها: `lib/site-meta.ts` و `lib/locales/<lang>/meta.ts`.
- راهنماها: `lib/guides/<lang>.ts`.
- صفحه‌های مقایسه («Cachety در برابر X»): `lib/compare/<lang>.ts`. هر ادعا دربارهٔ ابزار دیگر باید منبعش (`sources`) و تاریخ بررسی‌اش (`checked`) را داشته باشد، و هر صفحه باید بگوید چه وقت ابزار دیگر انتخاب بهتری است. این اطلاعات را مرتب دوباره بررسی کنید: سرویس‌ها تغییر می‌کنند.
- زبان‌های راست‌به‌چپ از کلاس‌های منطقی Tailwind ‏(`ms-`، `pe-`، `start-`، `end-`…) استفاده می‌کنند، نه `ml-`، `pr-`، `left-`، `right-`.

همهٔ زبان‌ها باید ساختار یکسانی داشته باشند؛ آزمون‌ها این را بررسی می‌کنند.

## از پروژه حمایت کنید

Cachety رایگان است و رایگان می‌ماند. اگر به کارتان آمد، می‌توانید [از طریق GitHub Sponsors از آن حمایت کنید](https://github.com/sponsors/amirhmoradi). کمک‌های مالی به پرداخت هزینهٔ نام دامنه و ابزارهای توسعه کمک می‌کنند، و بیش از همه به وقتی که این کار می‌گیرد.

امروز هیچ تبلیغی در کار نیست. شاید پروژه روزی چند پیوند حمایتیِ دست‌چین و هماهنگ با همین روحیه نشان دهد (ابزارهای رمزگذاری، نرم‌افزارهای متن‌باز، اشتراک‌گذاری امن اسناد). قواعد این پیوندها سخت‌گیرانه است و بخشی از تعهد ما به حریم خصوصی:

- به‌روشنی با عنوان «حمایتی» مشخص می‌شوند؛
- از دامنهٔ خود Cachety ارائه می‌شوند (فقط تصویر و پیوند): بدون شبکهٔ تبلیغاتی، بدون اسکریپت شخص ثالث، بدون پیکسل ردیابی؛
- هرگز بر اساس چیزی که کاربر در ابزار وارد می‌کند انتخاب یا نمایش داده نمی‌شوند؛
- سیاست Content-Security-Policy به همان سخت‌گیریِ امروز می‌ماند (`connect-src 'self'`).
